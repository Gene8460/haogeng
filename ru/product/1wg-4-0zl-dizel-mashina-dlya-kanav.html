Машина для канав 170 (Дракон)

Model: 1WG-4.0ZL
📋 Характеристики

Описание

Дизельный окучник-канавокопатель 170cc (1WG-4.0ZL) для огородов и садов. Превращает мотокультиватор в грядоделатель за один проход — копает борозды 250-400 мм при мощности 4.0 кВт. Та же компактная рама, пролезает в узкие междурядья, куда большая техника не пройдёт. 4-тактный двигатель с ручным стартером, общий вес 95 кг.

Подходит Для

  • Огороды: картофель, помидоры, перцы
  • Дренажные канавы в садах
  • Гряды в теплицах
  • Малые/средние участки 0.5-2 га
  • Заменить ручную копку при нехватке рабочих

Особенности

  • 170F бензин 4-тактный — 4.0 кВт / 5.4 л.с.
  • Глубина канавы: 250-400 мм
  • Ширина канавы: регулируемая
  • Прямой привод фреза + окучник
  • Коробка ковкий чугун для длительной работы
  • Ручной стартер — без аккумулятора
  • Вес нетто 95 кг
  • Переключение фреза/окучник без инструмента
  • Совместим со всеми базами 1WG-4.0
  • Регулируемая рукоятка для удобства оператора
